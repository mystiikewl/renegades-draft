# Description

Implement Phase 2 of the refactoring plan for the Renegades Draft Central app. Focus on modularization to improve maintainability and scalability. Extract hooks from components, decompose large components like DraftBoard.tsx into sub-components, create a service layer for Supabase queries, and ensure no breaking changes are introduced. This phase aims to reduce code complexity and enhance code reusability.

# Acceptance Criteria

- Extract and modularize hooks for state management (e.g., useDraftState, usePlayerData).
- Decompose monolithic components (e.g., DraftBoard.tsx into Header, List, Modal sub-components).
- Implement a service layer for Supabase interactions to abstract database queries.
- Update state management to use modular hooks without prop drilling.
- Ensure all changes are backward compatible and do not introduce regressions.
- Verify performance improvements through profiling.
- Document all new components and hooks in the project documentation.
