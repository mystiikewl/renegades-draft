# Description

The DraftTabs component turns into a dropdown on mobile, positioned directly above the OnClockBanner. The dropdown is visually overwhelmed by the banner's prominent styling (gradients, animations, shadows, team colors). Both elements are important, so enhance the dropdown's visibility to match the banner's visual weight without overwhelming the layout.

Key files:
- [DraftTabs.tsx](renegades-draft-central/src/components/draft/DraftTabs.tsx): Contains Tabs from Shadcn/UI, with DraftTabNavigation handling the mobile dropdown.
- [OnClockBanner.tsx](renegades-draft-central/src/components/draft/status/OnClockBanner.tsx): Example of prominent mobile styling (e.g., border-2, animations, teamPalette-based colors/shadows).

Acceptance Criteria:
- On mobile (use Tailwind sm/md breakpoints or similar), the dropdown trigger/button has enhanced styling: background gradient, border, subtle animation (e.g., pulse or hover scale), shadow for depth.
- Use similar team-based colors if applicable (from useDraftStatus hook), or neutral prominent styles (e.g., white/high-contrast text, bold font).
- Ensure no overlap/z-index issues; dropdown opens clearly above/below banner.
- Responsive: Test on mobile viewport (e.g., via browser dev tools); no breakage on desktop.
- Preserve functionality: Tab switching works, no regressions.
- Clean code: Use Tailwind classes where possible; inline styles only if needed for dynamics.
